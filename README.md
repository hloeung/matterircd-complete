Irssi script to complement matterircd (https://github.com/42wim/matterircd).

Supports thread/message ID completion, formatting, caching, search, live thread
preview, and typing indicators across the chat protocols/bridges supported by
matterircd: Mattermost, Matrix, Slack, Microsoft Teams (MSTeams), Google Chat,
and Rocket.Chat.

See the header comments in `matterircd_complete.pl` for setup, keybindings, and
configuration options.
